## Car Insurance

This project is an MVC web application that mimics a car insurance website. It takes user's input on policy information and calculates a quote based on business logic. There is also an admin page that allows staff to view all of the quotes that have been issued.

[View Repository](https://github.com/arifaie/CarInsurance)

## Student Code First

This project is a console application that uses Entity Framework Code-First to automatically create a Student database and add a student record. It demonstrates the Code-First workflow where C# classes define the database schema.

[View Repository](https://github.com/arifaie/StudentCodeFirst)
